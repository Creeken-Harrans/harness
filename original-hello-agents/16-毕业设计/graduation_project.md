# 第十六章 毕业设计：构建属于你的多智能体应用

恭喜你来到 Hello-Agents 教程的最后一章！在前面的 15 章中，我们从零开始构建了 HelloAgents 框架，学习了智能体的核心概念、多种范式、工具系统、记忆机制、通信协议、强化学习训练和性能评估等知识。在第 13-15 章中，我们还通过三个完整的实战项目（智能旅行助手、自动化深度研究智能体、赛博小镇）展示了如何将所学知识融会贯通。

## 毕业设计形式

你的毕业设计将以**开源项目**的形式提交到 Hello-Agents 的共创项目仓库（`Co-creation-projects`目录）。

具体格式请参考 `EXAMPLE-ProjectTemplate` 文件夹。

## 本目录包含

- `code_review_agent.py` — 完整的智能代码审查助手实现（教程推荐选题示例）
- `requirements.txt` — 项目依赖
- `EXAMPLE-ProjectTemplate/` — 毕业设计提交模板（含 README.md 模板）

## 运行方式

```bash
cd 16-毕业设计
pip install -r requirements.txt
python code_review_agent.py
```
